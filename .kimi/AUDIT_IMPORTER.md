## Что изменилось

- **`import('./ui.js')` удалён** — заменён на прямой вызов `renderScreen(state.activeScreen)`. Это устраняет критический runtime crash при импорте сессии.
- **Добавлен `_rolesLoading` флаг** — предотвращает race condition при двойном клике на кнопку загрузки ролей.
- **Добавлен `_rolesAbortController`** — позволяет отменить предыдущий `fetch` при новом вызове `loadRoles()`.
- **`fetchRoleFile` вынесена в отдельную функцию** — каждый запрос имеет свой `AbortController` + таймаут 10 секунд. Таймер гарантированно очищается в `finally`.
- **Загрузка ролей разбита на чанки по 5 файлов** — вместо 16 параллельных `fetch` теперь максимум 5 одновременно. Это снижает нагрузку на браузер и сервер.
- **`normalizeBaseUrl`** — корректно обрабатывает множественные слэши в конце URL.
- **Дедупликация `roleName`** — при дублировании имён ролей в консоль выводится предупреждение, дубликат пропускается.
- **`requestAnimationFrame` вместо `setTimeout(400)`** — переход на экран происходит по готовности отрисовки, а не по фиксированной задержке.
- **`exportSession` cleanup** — `URL.revokeObjectURL` и `removeChild` вызываются в `requestAnimationFrame` с проверкой `parentNode`.
- **`MAX_FILE_SIZE = 2 МБ`** — `.md` файлы ролей больше 2 МБ пропускаются с предупреждением в консоль.
- **`input.remove()`** — элемент `<input type="file">` удаляется из DOM сразу после выбора файлов.
